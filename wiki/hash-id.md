# Hash Identifier

Hash identifier and cracker: 50+ hash types, wordlist/rainbow table cracking.

```
python3 main.py hash-id --hash 5d41402abc4b2a76b9719d911017c592 --crack
```

**Options:**
- `--hash` — Single hash to identify
- `--hashes` — Comma-separated hashes
- `--crack` — Attempt cracking
- `--wordlist, -w` — Wordlist for cracking
- `--info` — Show hash info
